# Ascend InQ

[English](README.en.md) | 日本語

**Ascend in queue** — キューに潜るたびに上がっていくための、League of Legends 振り返りツール。

試合を自動で録画し、試合後に **動画＋シークバー＋場面ごとの解説** で振り返れます。

- 試合を自動で録画（GPUエンコードで超軽量。CPU使用率は全体の0.2%程度）
- 試合後に LoL クライアントから試合データを読み、デス・オブジェクト・レーン差などを分析（**APIキー不要**）
- ビューアで、シークバーの重要な場面をクリック → その場面の映像と「どうするべきだったか」が出る
- 録画が無くても、位置データからミニマップ上で10人の動きを再生できる

> 試合中に動くのは「録画」と「試合が続いているかの確認（数秒に1回、自分のPC内への小さな問い合わせ）」だけです。分析は試合後に行います。

## ダウンロードと使い方
1. [Releases](https://github.com/Jimonhitori/Ascend-InQ/releases) から `AscendInQ-windows.zip` をダウンロードして、好きなフォルダに展開
2. `AscendInQ.exe` を起動 → 画面右下のタスクトレイに金色の二重矢印アイコンが出ます
   - 初回は録画に必要な ffmpeg（無料の動画ツール、約85MB）のダウンロードを確認されます
   - 初回は設定画面が開くので、録画の保存先などを確認して保存
3. あとは LoL をプレイするだけ。試合が始まると自動で録画（アイコンに赤丸）、終わると分析して Ascend InQ のウィンドウに振り返りが表示されます
4. LoL をやめるときは、トレイアイコンを右クリック →「終了」

トレイアイコンの右クリックメニュー:
- **最新の試合を見る**（アイコンのダブルクリックでも開きます） / **試合一覧を開く**
- **直近の試合を取り込む** … 録画していない過去の試合もミニマップ再生と解説で見られます
- **自動録画** のオン/オフ、**試合後にビューアを開く** のオン/オフ
- 録画フォルダ・設定・ログを開く

録画・データ・レポートはすべて `AscendInQ.exe` と同じフォルダに保存されます（フォルダごと移動・削除できます）。

### 最初に「Windows によって PC が保護されました」と出たら
このアプリには有料のコード署名が無いため、初回起動時に Windows の警告が出ることがあります。
「詳細情報」→「実行」で起動できます。気になる場合は、ソースコードから自分でビルドすることもできます（下記）。

## 注意
- **LoL のウィンドウモードは「ボーダーレス」にしてください。** 「フルスクリーン」だと録画が真っ黒になることがあります（アプリが検出して通知します）
- **画面全体を録画します。** 試合中に Alt+Tab で切り替えた Discord などの画面も録画に残ります。録画を人に見せるときは注意してください
- Outplayed / OBS など他の録画ソフトの自動録画は止めておいてください（二重録画になります）
- 保存先の空き容量が 3GB 未満だと録画しません。1試合あたり約1GBです。古い録画は設定した本数を超えると自動で削除されます
- アプリが強制終了しても録画は自動で止まり、次回起動時に途中までの録画を復元します

## 設定
トレイメニューの「設定…」から変更できます。
| 項目 | 内容 |
|---|---|
| 試合データ | LoL クライアントから（APIキー不要・既定） / Riot APIキー（上級者向け） |
| 録画 | 試合全体 / 録画しない、保存先、残す本数、画質、フレームレート、モニター、マウスカーソル |
| 試合後 | 自動で分析する、ビューアを自動で開く |
| 一般 | 言語（日本語 / English）、PC起動時に起動、通知 |

## わかること・わからないこと
- **わかる（マクロ）**: デスの場所・人数・敵JGの位置、オブジェクトへの参加、CS/ゴールド/経験値差、アイテム完成時刻、ローム
- **わからない（ミクロ）**: スキルの当て合い、トレード、ウェーブの細かい状態 → ここは映像で確認
- 位置は1分ごとのデータとイベントからの推定です
- LoL クライアントのデータには「ワードを置いた記録」「アイテム購入の記録」「タワープレート」がありません。アイテムの完成時刻は録画中に15秒おきに記録して補います（録画していない試合は最終ビルドのみ）。ワード関連の判定は Riot APIキー使用時のみです
- ロール（TOP/JGなど）はリプレイファイルがあれば正確に、無ければ序盤の位置から推定します
- 試合の解説文とビューアは現在日本語のみです（アプリの画面・通知は英語にも対応）

## 必要なもの
- Windows 10/11
- 録画する場合: NVIDIA / AMD / Intel のGPU（ハードウェアエンコーダー）
- ffmpeg（初回起動時に自動でダウンロードできます）
- （任意）Riot API キー … 設定画面で「Riot APIキー」を選ぶと、クライアントに無い古い試合や他アカウントの試合も取得できます

## ソースから使う / ビルドする
```
git clone https://github.com/Jimonhitori/Ascend-InQ.git
cd Ascend-InQ
pip install -r requirements.txt
pythonw app.py          # トレイアプリとして起動
build.bat               # dist\AscendInQ\AscendInQ.exe を作る
```
Python 3.10 以上が必要です。テストは `pip install -r requirements-dev.txt` のあと `python -m pytest`。

### コマンド版（CLI）
```
python review.py record --open        # 自動録画（常駐）。試合後にビューアを開く
python review.py                      # 直近5試合を取り込んでレポート/ビューア作成
python review.py --open               # 同上＋最新試合のビューアを開く
python review.py view [試合ID]         # ビューアを開く（省略時は最新）
python review.py report 試合ID         # 保存済みデータから作り直し
python review.py clip [試合ID]         # デス場面を短い動画と静止画に切り出し（clips/）
```
`reports/index.html` に試合一覧と「何試合も続けて出ている改善点」がまとまります。

### ビューアの操作
- シークバーのアイコン / 右の一覧をクリック → その場面の少し前に飛んで解説を表示
- Space 再生/停止、←→ 5秒、N / P 次/前の重要場面
- 他のソフトで録った動画は「🎬 録画を開く」で読み込めます。時刻がずれたら下の「同期」で調整（試合ごとに記憶）
